# TypeScript Assignment – Next Level (A1)

## Assignment Overview

this repository contains my solution for the Typescript Next Level assignment. It includes 8 coding problems and 2 technical blog posts

The coding problem cover:

- Optional parameter and default values
- Union types and type narrowing with `typeof`
- Readonly tuples
- Generics, rest parameters and `keyof` constraints
- Interface and array filtering
- classes, inheritance and access modifiers (`protected`, `private`)
- Async function with `Promise<string>`

All solutions are in [`solutions.ts`](./solutions.ts).
